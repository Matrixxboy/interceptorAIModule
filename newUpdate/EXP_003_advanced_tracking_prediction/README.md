# EXP_003: Advanced Target Tracking, Prediction, and Interception

## Objective
To enhance the existing interception system by integrating multiple advanced deep-learning-based tracking approaches and mathematical prediction methods.

## Components

1. **Trackers:**
   - LPNet (Local Feature Extraction)
   - Siamese Network (SiamFC / SiamRPN)
   - TransT (Transformer-based Tracker)
   - LTMU (Long-term Tracking)

2. **Prediction Models:**
   - Linear and Polynomial Regression
   - Kalman Filter (and variations)

3. **Interception:**
   - Fuses tracking, depth estimation, and prediction to calculate precise interception points.
